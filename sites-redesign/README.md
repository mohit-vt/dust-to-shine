# Dust To Shine — Cinematic Sites Redesign

This folder mirrors the premium React/Vinext redesign currently published with OpenAI Sites. It includes the DTS logo-film intro, logo-derived green/indigo colour system, cinematic scroll reveals, responsive layouts, WhatsApp quote flow, privacy page and terms page.

## Run locally

1. Use Node.js 22.13 or newer.
2. Run npm install.
3. Run npm run dev.

The existing static website and GitHub Pages workflow at the repository root are intentionally preserved.
