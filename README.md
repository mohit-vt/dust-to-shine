# Dust To Shine Facility Management Services

Premium, animated landing page for Dust to Shine — an ISO 9001:2015 certified,
Udyam registered facility management and cleaning company in Chennai.

Plain HTML5 / CSS3 / vanilla JavaScript — no build step, no framework, no
dependencies. Deployed as-is via GitHub Pages.

## Structure

- `index.html` — page markup, SEO meta tags, LocalBusiness structured data
- `assets/css/style.css` — styling, layout and animations
- `assets/js/main.js` — scroll reveals, counters, pricing toggle, WhatsApp lead form
- `assets/img/` — logo and other images

## Local preview

Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Live website: https://mohit-vt.github.io/dust-to-shine/
